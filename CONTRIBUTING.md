# Contributing

The project is in its initial planning stage. Start with a discussion of a small Blender-only workflow before submitting large changes or assets.

- Use the workflow template and record enough context to reproduce the result.
- Include only material you have permission to publish; document its source and permissions.
- Separate personal preferences from correctness requirements.
- Label errors and corrections explicitly.
- Keep related asset variants in one dataset split to avoid evaluation leakage.
- Have another person reproduce examples before labeling them verified.
- Do not commit credentials, private data, generated caches, or large recordings without an agreed storage plan.

Code and dataset contribution licenses must be established before external contributions are accepted.
