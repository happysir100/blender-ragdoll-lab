# Blender Ragdoll Lab

A Blender ragdoll generator project, with reproducible workflows, personal workflow preferences, and training and validation examples for AI-assisted game development.

## First milestone: a Blender ragdoll generator

The initial tool will generate ragdolls entirely within Blender. Supported rigs, generation behavior, and interface will be defined during design. Unity integration is outside this first milestone.

This repository currently contains planning and example templates; it does not contain a working add-on or training dataset yet.

## Goals

- Capture tasks with reproducible starting states and verified outcomes.
- Distinguish technical requirements, project constraints, and personal preferences.
- Preserve demonstrations, corrections, and decision notes.
- Evaluate results on separate validation and test tasks.
- Make reviewed workflows useful to other game developers.

## Contents

- `docs/first-tool.md`: scope and open design decisions.
- `templates/workflow.md`: reusable demonstration record.
- `CONTRIBUTING.md`: example quality and contribution expectations.

## Data handling

Record exact Blender versions and relevant add-ons. Keep related assets and their variations in the same dataset split. Do not expose held-out solutions to the assistant during evaluation. Never commit credentials, private project assets, or recordings containing private information.

Code and dataset licensing will be selected before accepting external contributions or distributing assets for reuse. Public visibility alone does not grant a reuse license.
